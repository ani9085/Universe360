# 첫 탐험 플레이테스트

항법 모듈과 기지 모듈을 단일 Router에 연결했습니다. 우주 화면에서 WASD로 우주선을 움직여 목적지 고리에 진입하거나 버튼으로 항법을 시작할 수 있습니다. 항법과 연료 차감, 도착·착륙은 A1의 규칙을 따릅니다. 지도 위 천체의 위치와 크기는 플레이용 배치입니다. 천체 데이터는 기존 A1 카탈로그를 읽습니다.

표면에서 **광석 찾기**는 가까운 광석을 표시합니다. **채굴 시작하기**는 우주선 화물로 부족한 기지 재료를 채운 뒤 태양광 발전기와 채굴기를 설치합니다. B1 규칙으로 전체 순서를 먼저 검증하고 명령을 실행합니다. 채굴량은 B1 생산 tick과 매장량으로 계산합니다. 고급 기지 조작은 **기지 관리**에서 열 수 있습니다.

## 실행과 검증

```powershell
& $godot --path .
& $godot --headless --path . --fixed-fps 60 --script res://tests/expedition/run.gd
& $godot --path . --fixed-fps 60 --script res://tests/expedition/run.gd
```

| 검사 | 결과 |
| --- | --- |
| 헤드리스 통합 루프 | 22개 통과 |
| Windows Vulkan Forward+ 통합 루프와 화면 캡처 | 26개 통과 |
| G0 상태·저장 회귀 | 61개 통과 |
| A1 항법 회귀 | 53개 통과 |
| B1 기지 회귀 | 273개 통과 |
| Windows x64 내보내기 | `Universe360.exe` 생성 및 에디터 없이 Vulkan Forward+ 시작·종료 확인 |

통합 테스트는 지구 출발, 조종, 달 도착·착륙, 광석 표시·채굴, 자동 저장, 달 이륙, 화성 이동 중 달 생산, 화성 착륙 및 이어하기를 다룹니다.

실제 아동 플레이테스트, 전체 오프라인 환경 시험, 1080p 5분 성능 계측은 후속 검증 항목입니다. 이 빌드의 착륙 목적지는 달과 화성입니다. 기지 정제와 연구는 기지 관리에서 사용할 수 있습니다.
